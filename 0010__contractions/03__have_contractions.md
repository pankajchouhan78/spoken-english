# HAVE Contractions - have, has, had

> Contractions with "have", "has", and "had".
> Used in perfect tenses and possession.

---

## Overview

| Full Form | Contraction | Use |
|-----------|-------------|-----|
| I have | I've | Present Perfect / Possession |
| you have | you've | Present Perfect / Possession |
| he has | he's | Present Perfect / Possession |
| she has | she's | Present Perfect / Possession |
| it has | it's | Present Perfect |
| we have | we've | Present Perfect / Possession |
| they have | they've | Present Perfect / Possession |
| had | 'd | Past Perfect |

---

## I'VE (I have)

**Daily Use Sentences:**

1. I've finished my work.
   - Maine apna kaam khatam kar liya.

2. I've been here before.
   - Main yahaan pehle aa chuka hoon.

3. I've got a question.
   - Mera ek sawaal hai.

4. I've never seen this movie.
   - Maine ye film kabhi nahi dekhi.

5. I've already eaten.
   - Main kha chuka hoon.

6. I've known him for years.
   - Main use saalon se jaanta hoon.

7. I've got to go now.
   - Mujhe ab jaana hai.

8. I've been waiting for an hour.
   - Main ek ghante se wait kar raha hoon.

9. I've made a decision.
   - Maine faisla kar liya.

10. I've heard about it.
    - Maine iske baare mein suna hai.

## 'D (had) - Past Perfect

> I'd, you'd, he'd, she'd, we'd, they'd

**Daily Use Sentences:**

1. I'd finished before he came.
   - Uske aane se pehle main khatam kar chuka tha.

2. She'd already left when I called.
   - Jab maine call kiya, wo ja chuki thi.

3. They'd never seen snow before.
   - Unhone pehle kabhi baraf nahi dekhi thi.

4. We'd been waiting for hours.
   - Hum ghanton se wait kar rahe the.

5. He'd forgotten his wallet.
   - Wo apna wallet bhool gaya tha.

## 'D Confusion: HAD vs WOULD

| Contraction | Could Mean | Example | Context |
|-------------|------------|---------|---------|
| I'd | I had | I'd finished. | + V3 (past participle) |
| I'd | I would | I'd like tea. | + like/prefer/rather |

**How to Know:**

- **I'd + V3** = I had (past perfect)
  - I'd seen that movie. (I had seen)

- **I'd + V1** = I would (conditional)
  - I'd go if I could. (I would go)

**Examples:**

1. I'd already eaten. (I had)
   - Main kha chuka tha.

2. I'd love to come. (I would)
   - Main aana chahta hoon.

3. She'd finished the work. (She had)
   - Usne kaam khatam kar liya tha.

4. She'd rather stay home. (She would)
   - Wo ghar rehna pasand karegi.
