# Thanks, Apologies & Responses

> Common phrases for thanking, apologizing, and responding.

---

## Ways to Say "Thanks"

| English | Hindi |
|---------|-------|
| Thanks a lot! | Bohot bohot shukriya! |
| I really appreciate it! | Main iska sach mein bahut aabhaar hoon! |
| You're the best! | Tum sabse badhiya ho! |
| Thanks, I owe you one! | Shukriya, ab main tumhara ehsaanmaan hoon! |
| Thank you so much for your help. | Aapki madad ke liye bohot shukriya. |
| I sincerely appreciate your assistance. | Main dil se aapki madad ka aabhaar karta hoon. |
| Thank you for your support. | Aapke samarthan ke liye dhanyavaad. |
| I'm very grateful for your help. | Main aapki madad ke liye bahut abhaari hoon. |

---

## Responses to "Thank You"

| English | Hindi |
|---------|-------|
| You're welcome! | Aapka swaagat hai! |
| No problem! | Koi baat nahi! |
| My pleasure! | Mujhe khushi hui! |
| Don't mention it! | Iska zikr mat kijiye! |
| Happy to help! | Madad karke khushi hui! |
| Anytime! | Kabhi bhi! |
| It was nothing! | Yeh toh kuch bhi nahi tha! |
| Glad I could help! | Khushi hui ki main madad kar paaya! |

---

## Ways to Apologize

| English | Hindi |
|---------|-------|
| I'm sorry. | Mujhe maaf kar do. |
| I apologize. | Main maafi maangta hoon. |
| Sorry for the mistake. | Galti ke liye maafi chahta hoon. |
| I didn't mean to upset you. | Mera irada aapko pareshan karne ka nahi tha. |
| It won't happen again. | Aisa dobara nahi hoga. |
| Please forgive me. | Kripya mujhe maaf kar do. |
| I'm really sorry for the inconvenience. | Pareshani ke liye main sach mein sharminda hoon. |

---

## Responses to an Apology

| English | Hindi |
|---------|-------|
| It's okay. | Koi baat nahi. |
| No problem. | Koi dikkat nahi hai. |
| Don't worry about it. | Chinta mat karo. |
| I forgive you. | Main tumhe maaf karta hoon. |
| Let's move on. | Chalo, aage badhte hain. |
| It happens, don't worry. | Aisa hota hai, chinta mat karo. |
| We're good now. | Ab sab theek hai. |
