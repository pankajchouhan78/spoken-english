# Common Verbs in Sentences

> Sentences using common verbs: Start, Keep, Stop

---

## START

| English | Hindi |
|---------|-------|
| Start writing your report today. | Aaj hi apna report likhna shuru karo. |
| Start studying for the exam next week. | Agle hafte ke exam ke liye padhai shuru karo. |
| Start exercising regularly to stay fit. | Fit rehne ke liye regular exercise shuru karo. |
| Start cooking dinner early today. | Aaj dinner jaldi banane shuru karo. |
| Start the engine and let's go. | Engine chalu karo aur chalo. |

---

## KEEP

| English | Hindi |
|---------|-------|
| Keep writing until you finish the chapter. | Chapter khatam hone tak likhte raho. |
| Keep practicing to improve your skills. | Apni skills ko improve karne ke liye practice karte raho. |
| Keep working hard, success will follow. | Mehnat karte raho, success zarur milegi. |
| Keep running until you reach the finish line. | Finish line tak daudhte raho. |
| Keep learning new things every day. | Har din kuch naya seekhte raho. |

---

## STOP

| English | Hindi |
|---------|-------|
| Stop writing once the time is up. | Time khatam hote hi likhna band karo. |
| Stop talking during the meeting. | Meeting ke dauran baat karna band karo. |
| Stop watching TV and start studying. | TV dekhna band karo aur padhai shuru karo. |
| Stop worrying about the result. | Result ke baare mein chinta karna band karo. |
| Stop running if you feel tired. | Agar thakawat ho to daudhna band karo. |

---

## "I Feel Like" - Jab Dil Se Kuch Karne Ka Mann Ho!

| English | Hindi |
|---------|-------|
| I feel like going out. | Mujhe bahar jaane ka mann hai. |
| I feel like eating something sweet. | Mujhe kuch meetha khane ka mann hai. |
| I feel like watching a movie. | Mujhe ek movie dekhne ka mann hai. |
| I feel like I need a break. | Mujhe lagta hai mujhe ek break ki zarurat hai. |
| I feel like dancing. | Mujhe naachne ka mann hai. |
| I feel like this is the right decision. | Mujhe lagta hai yeh sahi faisla hai. |
| I feel like talking to someone. | Mujhe kisi se baat karne ka mann hai. |
