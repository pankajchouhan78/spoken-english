# Constructions - Introduction & Types

> Constructions are FIXED PATTERNS used to express specific meanings.
> They follow a set structure that cannot be changed.

---

## What are Constructions?

Constructions are sentence patterns that:
- Have a **fixed structure**
- Express a **specific meaning**
- Are used **frequently in daily speech**

---

## Common Construction Types

| Type | Pattern | Example |
|------|---------|---------|
| Existence | There is/are... | There is a book on the table. |
| Dummy Subject | It is... | It is raining. |
| Past Habit | Used to... | I used to play cricket. |
| Preference | Would rather... | I would rather stay home. |
| Advice | Had better... | You had better leave now. |
| Result | So...that | He is so tall that he can touch the ceiling. |
| Degree | Too...to | It's too hot to go outside. |
| Sufficiency | Enough...to | She is old enough to drive. |
| Comparison | The more...the more | The more you practice, the better you get. |
| Imaginary | As if/As though | He talks as if he knows everything. |

## Quick Reference Chart

### Existence Constructions

| Pattern | Use | Hindi |
|---------|-----|-------|
| There is + singular | One thing exists | Ek cheez hai |
| There are + plural | Many things exist | Bahut cheezein hain |
| There was/were | Past existence | Tha/The |

### Time-Related Constructions

| Pattern | Use | Hindi |
|---------|-----|-------|
| Used to + V1 | Past habit (no more) | Pehle karta tha |
| Be used to + V-ing | Accustomed to | Aadat hai |
| Get used to + V-ing | Becoming accustomed | Aadat pad rahi hai |

### Preference Constructions

| Pattern | Use | Hindi |
|---------|-----|-------|
| Would rather + V1 | Prefer to do | Pasand karunga |
| Had better + V1 | Strong advice | Behtar hoga |
| Prefer + V-ing/noun | Like more | Zyada pasand |

### Degree/Result Constructions

| Pattern | Use | Hindi |
|---------|-----|-------|
| So + adj + that | Result (with adjective) | Itna...ki |
| Such + noun + that | Result (with noun) | Aisa...ki |
| Too + adj + to | Excessive (negative result) | Bahut zyada |
| Adj + enough + to | Sufficient (positive result) | Kaafi |

### Comparison Constructions

| Pattern | Use | Hindi |
|---------|-----|-------|
| The more...the more | Parallel increase | Jitna...utna |
| As if / As though | Imaginary comparison | Jaise ki |
| No sooner...than | Immediate sequence | Jaise hi...waise hi |

## Common Patterns Summary

```
EXISTENCE:      There + is/are + noun + location
DUMMY IT:       It + is + adj/noun + to-infinitive
PAST HABIT:     Subject + used to + V1
ACCUSTOMED:     Subject + be + used to + V-ing
PREFERENCE:     Subject + would rather + V1 + than + V1
ADVICE:         Subject + had better + V1
RESULT:         So + adj + that + clause
DEGREE:         Too + adj + to + V1
SUFFICIENCY:    Adj + enough + to + V1
COMPARISON:     The + comparative + clause, the + comparative + clause
```
