# There Is / There Are - Existence Construction

> Used to say that something EXISTS or is PRESENT.
> "There" is a dummy subject (not real subject).

---

## Structure

| Tense | Singular | Plural |
|-------|----------|--------|
| Present | There **is** | There **are** |
| Past | There **was** | There **were** |
| Future | There **will be** | There **will be** |
| Perfect | There **has been** | There **have been** |

---

## THERE IS (Singular)

> Use with ONE thing or UNCOUNTABLE nouns.

**Daily Use Sentences:**

1. There is a book on the table.
   - Table par ek kitaab hai.

2. There is a problem with my phone.
   - Mere phone mein ek problem hai.

3. There is a man at the door.
   - Darwaze par ek aadmi hai.

4. There is some water in the bottle.
   - Bottle mein kuch paani hai.

5. There is a meeting at 3 PM.
   - 3 baje ek meeting hai.

6. There is a good restaurant nearby.
   - Paas mein ek accha restaurant hai.

7. There is milk in the fridge.
   - Fridge mein doodh hai.

8. There is no time left.
   - Time nahi bacha.

9. There is a fly in my soup.
   - Mere soup mein makhi hai.

10. There is something wrong.
    - Kuch gadbad hai.

11. There is a lot of traffic today.
    - Aaj bahut traffic hai.

12. There is a beautiful park here.
    - Yahaan ek sundar park hai.

13. There is no doubt about it.
    - Isme koi shak nahi.

14. There is a chance he'll come.
    - Uske aane ki ummeed hai.

15. There is plenty of food.
    - Khana bahut hai.

## THERE ARE (Plural)

> Use with MORE THAN ONE thing.

**Daily Use Sentences:**

1. There are many books on the shelf.
   - Shelf par bahut kitaabein hain.

2. There are two chairs in the room.
   - Kamre mein do kursiyan hain.

3. There are some apples in the basket.
   - Basket mein kuch seb hain.

4. There are many students in the class.
   - Class mein bahut students hain.

5. There are three messages for you.
   - Tumhare liye teen messages hain.

6. There are several options available.
   - Kai options available hain.

7. There are no tickets left.
   - Tickets nahi bache.

8. There are many people waiting.
   - Bahut log wait kar rahe hain.

9. There are some mistakes in your work.
   - Tumhare kaam mein kuch galtiyan hain.

10. There are five members in my family.
    - Mere parivaar mein paanch log hain.

11. There are many cars on the road.
    - Road par bahut cars hain.

12. There are few good teachers here.
    - Yahaan acche teachers kam hain.

13. There are no excuses this time.
    - Is baar koi bahana nahi.

14. There are a lot of problems.
    - Bahut problems hain.

15. There are many reasons for this.
    - Iske bahut kaaran hain.

## THERE WAS / THERE WERE (Past)

**Daily Use Sentences:**

1. There was a party yesterday.
   - Kal ek party thi.

2. There was an accident on the road.
   - Road par ek accident hua.

3. There were many guests at the wedding.
   - Shaadi mein bahut mehman the.

4. There was no electricity last night.
   - Kal raat bijli nahi thi.

5. There were some issues earlier.
   - Pehle kuch issues the.

6. There was a time when I was young.
   - Ek waqt tha jab main jawan tha.

7. There were many trees here before.
   - Pehle yahaan bahut ped the.

8. There was nothing to eat.
   - Khane ko kuch nahi tha.

9. There was a snake in the garden.
   - Baghiche mein saanp tha.

10. There were no phones in those days.
    - Un dino mein phone nahi the.

## Negative & Questions

### Negative

| Form | Example |
|------|---------|
| There is no... | There is no milk. |
| There isn't any... | There isn't any water. |
| There are no... | There are no chairs. |
| There aren't any... | There aren't any books. |

**Sentences:**

1. There is no problem here.
   - Yahaan koi problem nahi.

2. There isn't any sugar.
   - Sugar nahi hai.

3. There are no seats available.
   - Seats available nahi hain.

4. There aren't any questions.
   - Koi sawaal nahi hai.

5. There was no one at home.
   - Ghar par koi nahi tha.

---

### Questions

| Form | Example |
|------|---------|
| Is there...? | Is there any milk? |
| Are there...? | Are there any seats? |
| How many...are there? | How many books are there? |

**Sentences:**

1. Is there a bank nearby?
   - Kya paas mein koi bank hai?

2. Are there any questions?
   - Koi sawaal hai?

3. Is there any water left?
   - Kya paani bacha hai?

4. Are there any tickets available?
   - Kya tickets available hain?

5. How many people are there?
   - Kitne log hain?

6. Was there anyone at home?
   - Kya ghar par koi tha?

7. Were there any problems?
   - Kya koi problems thi?

8. Is there enough time?
   - Kya kaafi time hai?

9. Are there many options?
   - Kya bahut options hain?

10. Will there be food at the party?
    - Kya party mein khana hoga?

---

## Future: There Will Be

**Daily Use Sentences:**

1. There will be a meeting tomorrow.
   - Kal ek meeting hogi.

2. There will be many changes.
   - Bahut badlaav honge.

3. There will be rain tonight.
   - Aaj raat baarish hogi.

4. There won't be any problem.
   - Koi problem nahi hogi.

5. There will be a surprise for you.
   - Tumhare liye surprise hoga.
