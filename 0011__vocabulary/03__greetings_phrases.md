# Greetings & Common Phrases

> Essential phrases for everyday conversations.
> Master these for smooth social interactions.

---

## Basic Greetings

| English | Hindi | When to Use |
|---------|-------|-------------|
| Hello | Namaste | Any time |
| Hi | Hi | Informal, any time |
| Hey | Hey | Very informal |
| Good morning | Suprabhat | Before 12 PM |
| Good afternoon | Namaskar | 12 PM - 5 PM |
| Good evening | Shubh sandhya | After 5 PM |
| Good night | Shubh ratri | Before sleeping |
| Goodbye | Alvida | When leaving |
| Bye | Bye | Informal leaving |
| See you | Phir milenge | When parting |
| Take care | Apna khayal rakhna | Caring goodbye |

## How Are You? (Variations)

| Question | Hindi | Response |
|----------|-------|----------|
| How are you? | Aap kaise hain? | I'm fine, thanks. |
| How's it going? | Kya haal hai? | It's going well. |
| How have you been? | Kaise rahe? | I've been good. |
| What's up? | Kya chal raha? | Not much. |
| How's everything? | Sab kaisa hai? | Everything's good. |
| How's life? | Life kaisi hai? | Life is good. |
| How are things? | Kya haal chaal? | Things are fine. |

## Responses to "How are you?"

| Response | Hindi | Mood |
|----------|-------|------|
| I'm fine. | Main theek hoon. | Normal |
| I'm good. | Main accha hoon. | Positive |
| I'm great! | Bahut accha! | Very positive |
| I'm okay. | Theek thaak. | Neutral |
| Not bad. | Bura nahi. | Okay |
| Could be better. | Aur accha ho sakta tha. | Not great |
| I'm not well. | Tabiyat theek nahi. | Sick |
| I'm tired. | Thaka hua hoon. | Tired |
| I'm busy. | Busy hoon. | Working |

## Thank You & Sorry

### Thanking

| English | Hindi | Level |
|---------|-------|-------|
| Thanks. | Shukriya. | Casual |
| Thank you. | Dhanyawaad. | Polite |
| Thank you so much. | Bahut shukriya. | More grateful |
| Thanks a lot. | Bohot thanks. | Casual grateful |
| I really appreciate it. | Bahut meherbaani. | Formal |

## Requests & Offers

### Making Requests

| English | Hindi | Politeness |
|---------|-------|------------|
| Please... | Kripya... | Basic polite |
| Can you...? | Kya tum...? | Casual |
| Could you...? | Kya aap...? | Polite |
| Would you mind...? | Agar aapko bura na lage... | Very polite |
| Do you mind if...? | Agar main... | Asking permission |
| May I...? | Kya main...? | Formal permission |

### Responding to Requests

| English | Hindi | Type |
|---------|-------|------|
| Sure. | Zaroor. | Yes |
| Of course. | Bilkul. | Strong yes |
| No problem. | Koi problem nahi. | Yes |
| Go ahead. | Haan, karo. | Yes |
| I'm sorry, I can't. | Sorry, nahi ho sakta. | No |
| I wish I could. | Kaash kar sakta. | Regretful no |

## Introductions

| English | Hindi |
|---------|-------|
| What's your name? | Aapka naam kya hai? |
| My name is... | Mera naam ... hai. |
| Nice to meet you. | Aapse milkar khushi hui. |

| I'm from... | Main ... se hoon. |
| I work at... | Main ... mein kaam karta hoon. |
