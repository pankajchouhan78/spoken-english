# Opposites (Antonyms)

> Learning opposites helps you learn TWO words at once!
> Very effective vocabulary building technique.

---

## Common Pairs in Sentences

| Sentence | Opposite Sentence |
|----------|-------------------|
| The door is open. | The door is closed. |
| It's very hot today. | It's very cold today. |
| I'm happy now. | I'm sad now. |
| He came early. | He came late. |
| The box is full. | The box is empty. |
| This is easy. | This is difficult. |
| I love this. | I hate this. |
| Buy it now. | Sell it now. |
| Start the work. | Stop the work. |
| She won the game. | She lost the game. |
