## Using Colors & Shapes

### Describing Objects

| Sentence | Hindi |
|----------|-------|
| The ball is round. | Gend gol hai. |
| It's a blue car. | Ye neeli gaadi hai. |
| Draw a circle. | Ek gol banaao. |
| The box is square. | Dabba chaukona hai. |
| I want the red one. | Mujhe laal wala chahiye. |
| Cut it into triangles. | Ise tribhuj mein kaato. |

### Common Combinations

| Phrase | Hindi |
|--------|-------|
| Black and white | Kaala aur safed |
| Red and blue | Laal aur neela |
| All shapes and sizes | Har shape aur size |
| Rainbow colors | Indradhanush ke rang |
| Same color | Ek hi rang |
| Different shapes | Alag alag shapes |
