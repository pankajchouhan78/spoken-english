## Personality Phrases

| English | Hindi |
|---------|-------|
| He is very kind. | Woh bahut dayalu hai. |
| She's hardworking. | Woh mehanti hai. |
| Don't be lazy. | Aalsi mat bano. |
| He's honest. | Woh imaandaar hai. |
| She's so friendly. | Woh bahut milansar hai. |
| You're very patient. | Tum bahut sabar wale ho. |
| He's a bit stubborn. | Woh thoda ziddi hai. |
| She's confident. | Usmein confidence hai. |
| Don't be rude. | Badtameezi mat karo. |
| He's very generous. | Woh bahut daani hai. |

## Asking About Personality

| English | Hindi |
|---------|-------|
| What's he like? | Woh kaisa hai? |
| How would you describe her? | Usse kaise describe karoge? |
| Is he friendly? | Kya woh milansar hai? |
| What kind of person is she? | Woh kaisi insaan hai? |
| How's his nature? | Uski nature kaisi hai? |
