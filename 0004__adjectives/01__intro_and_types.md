# Adjectives - Introduction & Types

> Words that describe or modify nouns (people, places, things).

---

## What is an Adjective?

An adjective tells us **what kind**, **how many**, **which one**, or **whose**.

**Formula:** Adjective + Noun

**Examples:**
- Beautiful girl (sundar ladki)
- Big house (bada ghar)
- Five books (paanch kitaabein)
- This pen (ye pen)

---

## Types of Adjectives

| Type | Description | Example |
|------|-------------|---------|
| Descriptive | Describe quality | beautiful, tall, smart |
| Quantitative | Show quantity | some, much, little |
| Numeral | Show number | one, first, many |
| Demonstrative | Point out which | this, that, these |
| Possessive | Show ownership | my, your, his |
| Interrogative | Ask questions | which, what, whose |
| Distributive | Refer to each | each, every, either |

## 2. Quantitative Adjectives

> Tell us HOW MUCH of something

| English | Hindi | Example Sentence |
|---------|-------|------------------|
| some | kuch | Give me some water. |
| any | koi bhi | Is there any problem? |
| much | bahut | I don't have much time. |
| little | thoda | I have little money. |
| enough | kaafi | We have enough food. |
| all | sab | All students passed. |
| no | koi nahi | I have no doubt. |
| whole | pura | I ate the whole pizza. |
| half | aadha | Give me half of it. |
| sufficient | paryaapt | We have sufficient resources. |

**Daily Use Sentences:**

1. I need some help.
   - Mujhe kuch madad chahiye.

2. There isn't much time left.
   - Zyada time nahi bacha.

3. Do you have any questions?
   - Kya tumhara koi sawaal hai?

4. I have little patience.
   - Mere paas thoda sabr hai.

5. We have enough money for this.
   - Hamare paas iske liye kaafi paise hain.

6. All members are present.
   - Sabhi members maujood hain.

7. I have no problem with this.
   - Mujhe isse koi problem nahi.

8. The whole class laughed.
   - Puri class hansi.

9. Half the work is done.
   - Aadha kaam ho gaya.

10. Is this amount sufficient?
    - Kya ye amount paryaapt hai?

## 4. Demonstrative Adjectives

> Point out WHICH noun

| English | Hindi | Use |
|---------|-------|-----|
| this | ye/yeh | Near, singular |
| that | wo/woh | Far, singular |
| these | ye sab | Near, plural |
| those | wo sab | Far, plural |
| such | aisa | Of this type |

**Daily Use Sentences:**

1. This book is mine.
   - Ye kitaab meri hai.

2. That car is expensive.
   - Wo car mehengi hai.

3. These mangoes are sweet.
   - Ye aam meethe hain.

4. Those houses are old.
   - Wo ghar purane hain.

5. I've never seen such a thing.
   - Maine aisi cheez kabhi nahi dekhi.

6. This is my favorite song.
   - Ye mera favorite gaana hai.

7. That day was memorable.
   - Wo din yaadgaar tha.

8. These days, I'm very busy.
   - Aaj kal main bahut busy hoon.

9. Those were the golden days.
   - Wo sunahre din the.

10. Don't do such things.
    - Aisi cheezein mat karo.

## 6. Interrogative Adjectives

> Ask questions about nouns

| English | Hindi | Example |
|---------|-------|---------|
| which | kaun sa | Which book do you want? |
| what | kya/kaisa | What color is this? |
| whose | kiska | Whose pen is this? |

**Daily Use Sentences:**

1. Which way should I go?
   - Main kaun se raaste se jaun?

2. What time is it?
   - Kya time hua?

3. Whose bag is this?
   - Ye kiska bag hai?

4. Which movie do you like?
   - Tumhe kaun si movie pasand hai?

5. What kind of food do you want?
   - Tumhe kaisa khana chahiye?

6. Which class are you in?
   - Tum kaun si class mein ho?

7. Whose turn is it?
   - Kiski baari hai?

8. What size do you need?
   - Tumhe kaun sa size chahiye?

9. Which phone should I buy?
   - Main kaun sa phone lun?

10. Whose idea was this?
    - Ye kiska idea tha?

## 7. Distributive Adjectives

> Refer to each member separately

| English | Hindi | Example |
|---------|-------|---------|
| each | har ek | Each student got a prize. |
| every | har | Every person is important. |
| either | koi ek (2 mein se) | Take either book. |
| neither | koi nahi (2 mein se) | Neither option is good. |
| any | koi bhi | Choose any color. |

**Daily Use Sentences:**

1. Each student must work hard.
   - Har student ko mehnat karni chahiye.

2. Every day brings new hope.
   - Har din nayi ummeed laata hai.

3. You can take either side.
   - Tum koi bhi taraf le sakte ho.

4. Neither answer is correct.
   - Dono mein se koi jawab sahi nahi hai.

5. Each of us has a role.
   - Hum mein se har ek ki bhumika hai.

6. Every member participated.
   - Har member ne hissa liya.

7. Either way works for me.
   - Dono mein se koi bhi tarika mujhe chalega.

8. Neither team played well.
   - Dono mein se koi team acchi nahi kheli.

9. Each person is unique.
   - Har vyakti unique hai.

10. Every effort counts.
    - Har koshish mayne rakhti hai.
