# Travel & Directions

> Common phrases for traveling and asking directions.

---

## Asking for Directions

| English | Hindi |
|---------|-------|
| Excuse me, where is the station? | Excuse me, station kahan hai? |
| How do I get to the mall? | Mall kaise jaana hai? |
| Is it far from here? | Kya yeh yahan se door hai? |
| Can you show me on the map? | Kya aap map pe dikha sakte ho? |
| Which way is the market? | Market kis taraf hai? |
| Am I going the right way? | Kya main sahi raaste pe hoon? |

---

## Giving Directions

| English | Hindi |
|---------|-------|
| Go straight. | Seedha jaao. |
| Turn left. | Left mudo. |
| Turn right. | Right mudo. |
| It's on your left. | Yeh aapke left mein hai. |
| It's on your right. | Yeh aapke right mein hai. |
| Take the first turn. | Pehli gali lelo. |
| It's next to the bank. | Yeh bank ke paas hai. |
| It's opposite the hospital. | Yeh hospital ke saamne hai. |
| It's about 5 minutes from here. | Yahan se 5 minute door hai. |

---

## Using Public Transport

| English | Hindi |
|---------|-------|
| Where is the bus stop? | Bus stop kahan hai? |
| Which bus goes to the airport? | Airport ke liye kaun si bus jaati hai? |
| How much is the fare? | Kiraya kitna hai? |
| Does this train go to Mumbai? | Kya yeh train Mumbai jaati hai? |
| What time is the next train? | Agli train kitne baje hai? |
| Is this seat taken? | Kya yeh seat reserved hai? |
| Where should I get off? | Mujhe kahan utarna hai? |
| Please tell me when we reach. | Please batana jab hum pahunch jaayein. |

---

## Taking a Cab/Auto

| English | Hindi |
|---------|-------|
| I need a cab to the airport. | Mujhe airport ke liye cab chahiye. |
| How much will it cost? | Kitna lagega? |
| Please use the meter. | Meter se chalao. |
| Can you go faster? | Kya aap tez chal sakte ho? |
| Please slow down. | Thoda dheere chalo. |
| Stop here, please. | Yahan ruk jaao. |
| Keep the change. | Baaki rakh lo. |
| Can you wait here? | Kya aap yahan ruk sakte ho? |

---

## At the Airport/Station

| English | Hindi |
|---------|-------|
| Where is the check-in counter? | Check-in counter kahan hai? |
| I'd like a window seat. | Mujhe window seat chahiye. |
| Where is the boarding gate? | Boarding gate kahan hai? |
| Is my flight on time? | Kya meri flight time pe hai? |
| Where can I get a trolley? | Trolley kahan milegi? |
| Where is the baggage claim? | Luggage kahan milega? |
| I've lost my luggage. | Mera luggage kho gaya. |

## Booking & Tickets

| English | Hindi |
|---------|-------|
| I want to book a ticket. | Mujhe ticket book karna hai. |
| One ticket to Delhi, please. | Delhi ka ek ticket dijiye. |
| Is there a discount? | Koi discount hai? |
| Can I change my booking? | Kya main booking change kar sakta hoon? |
| I want to cancel my ticket. | Main ticket cancel karna chahta hoon. |
| Is this ticket refundable? | Kya is ticket ka refund milega? |
