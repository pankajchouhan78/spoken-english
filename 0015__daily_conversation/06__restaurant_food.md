# Restaurant & Food Conversations

> Common phrases for ordering food and dining out.

---

## Arriving at Restaurant

| English | Hindi |
|---------|-------|
| Table for two, please. | Do logon ke liye table chahiye. |
| Do you have a reservation? | Kya aapne reservation kiya hai? |
| How long is the wait? | Kitni der wait karna hoga? |
| Can we sit outside? | Kya hum bahar baith sakte hain? |
| Is this table available? | Kya yeh table khaali hai? |

---

## Ordering Food

| English | Hindi |
|---------|-------|
| Can I see the menu? | Menu dikha dijiye. |
| What do you recommend? | Aap kya recommend karenge? |
| What's today's special? | Aaj ka special kya hai? |
| I'll have the... | Main... lunga. |
| I'd like to order... | Main... order karna chahunga. |
| One more of the same, please. | Ek aur same wala. |

---

## Special Requests

| English | Hindi |
|---------|-------|
| Is this spicy? | Kya yeh teekha hai? |
| Can you make it less spicy? | Kya kam teekha bana sakte ho? |
| I'm allergic to nuts. | Mujhe nuts se allergy hai. |
| I'm vegetarian. | Main vegetarian hoon. |
| No onion and garlic, please. | Pyaaz lahsun nahi chahiye. |
| Can I get this without cheese? | Bina cheese ke mil sakta hai? |

---

## During the Meal

| English | Hindi |
|---------|-------|
| This is delicious! | Yeh bahut tasty hai! |
| Can I have some water? | Paani mil sakta hai? |
| Could we get some napkins? | Kuch napkins mil sakte hain? |
| This is not what I ordered. | Maine yeh order nahi kiya tha. |
| The food is cold. | Khana thanda hai. |
| Can you heat this up? | Kya aap yeh garam kar sakte ho? |

---

## Finishing Up

| English | Hindi |
|---------|-------|
| Can I have the bill, please? | Bill de dijiye. |
| We'd like to pay. | Hum pay karna chahte hain. |
| Can we split the bill? | Bill alag alag ho sakta hai? |
| Keep the change. | Baaki rakh lo. |
| Do you accept cards? | Card chalega? |
| Is service charge included? | Service charge included hai? |

---

## Takeaway & Delivery

| English | Hindi |
|---------|-------|
| Is this for here or to go? | Yahan khaoge ya pack karna hai? |
| I want to order takeaway. | Mujhe parcel chahiye. |
| Can you pack this? | Kya yeh pack kar sakte ho? |
| How long will delivery take? | Delivery mein kitna time lagega? |
| What's the delivery charge? | Delivery charge kya hai? |
| Can I track my order? | Order track kar sakta hoon? |

---

## Compliments & Complaints

| English | Hindi |
|---------|-------|
| The food was amazing! | Khana bahut achha tha! |
| Please compliment the chef. | Chef ko meri taraf se compliment dena. |
| I loved it! | Mujhe bahut pasand aaya! |
| This wasn't good. | Yeh achha nahi tha. |
| I'd like to speak to the manager. | Mujhe manager se baat karni hai. |
| We had a great experience. | Humara experience bahut achha raha. |
