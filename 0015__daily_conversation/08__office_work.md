# Office & Work Conversations

> Common phrases for workplace communication.

---

## Arriving at Work

| English | Hindi |
|---------|-------|
| Good morning, everyone! | Good morning sabko! |
| Sorry, I'm late. | Sorry, mujhe der ho gayi. |
| The traffic was terrible. | Traffic bahut kharab thi. |
| I got stuck in a meeting. | Main meeting mein fasa tha. |
| Let me settle in first. | Pehle main settle ho jaata hoon. |

---

## In Meetings

| English | Hindi |
|---------|-------|
| Let's get started. | Chalo shuru karte hain. |
| Can everyone hear me? | Kya sabko meri awaaz aa rahi hai? |
| I'd like to add something. | Main kuch add karna chahunga. |
| Can you share your screen? | Kya aap screen share kar sakte ho? |
| Let me share my thoughts. | Main apne thoughts share karta hoon. |
| I agree with that point. | Main is point se agree karta hoon. |
| Can we discuss this later? | Kya hum yeh baad mein discuss kar sakte hain? |
| Let's wrap up. | Chalo band karte hain. |

---

## Asking for Help

| English | Hindi |
|---------|-------|
| Can you help me with this? | Kya aap isme madad kar sakte ho? |
| I'm stuck on something. | Main kisi cheez mein fasa hoon. |
| Do you have a minute? | Kya aapke paas ek minute hai? |
| Can I ask you something? | Kya main kuch pooch sakta hoon? |
| I need your input on this. | Mujhe is par aapka input chahiye. |
| Could you review this? | Kya aap yeh review kar sakte ho? |

## Deadlines & Tasks

| English | Hindi |
|---------|-------|
| When is the deadline? | Deadline kab hai? |
| I'll finish it by EOD. | Main aaj shaam tak kar dunga. |
| Can I get an extension? | Kya mujhe thoda extra time mil sakta hai? |
| I'm working on it. | Main is par kaam kar raha hoon. |
| It's almost done. | Almost ho gaya hai. |
| I'll update you soon. | Main jaldi update karunga. |
| This is urgent. | Yeh urgent hai. |
| Let me prioritize this. | Main ise priority deta hoon. |

## Emails & Communication

| English | Hindi |
|---------|-------|
| Did you get my email? | Kya aapko meri email mili? |
| I'll send you the details. | Main aapko details bhej dunga. |
| Please check your inbox. | Apna inbox check karo. |
| I've CC'd you on the email. | Maine aapko CC kiya hai. |
| Let me loop in the team. | Main team ko add karta hoon. |
| Can you forward this? | Kya aap yeh forward kar sakte ho? |

## Leaving Work

| English | Hindi |
|---------|-------|
| I'm heading out. | Main nikal raha hoon. |
| See you tomorrow! | Kal milte hain! |
| Have a good evening! | Achhi shaam ho! |
| I'm done for the day. | Mera aaj ka kaam ho gaya. |
| I'm logging off now. | Main ab log off kar raha hoon. |
| Let's continue tomorrow. | Kal continue karte hain. |
