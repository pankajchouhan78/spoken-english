# Expressing Opinions & Feelings

> How to share your thoughts and feelings daily.

---

## Expressing Opinions

| English | Hindi |
|---------|-------|
| I think this is a good idea. | Mujhe lagta hai yeh achha idea hai. |
| In my opinion, we should wait. | Mere hisab se hume rukna chahiye. |
| I believe he is right. | Mujhe lagta hai woh sahi hai. |
| I feel like we need more time. | Mujhe lagta hai hume aur time chahiye. |
| As far as I know, it's closed. | Jahan tak mujhe pata hai, yeh band hai. |
| From my point of view... | Mere nazariye se... |
| If you ask me... | Agar mujhse poocho toh... |
| Personally, I prefer tea. | Mujhe personally chai pasand hai. |

## Agreeing

| English | Hindi |
|---------|-------|
| I agree with you. | Main aapse sehmat hoon. |
| You're absolutely right. | Aap bilkul sahi keh rahe ho. |
| That's exactly what I think. | Main bhi yahi sochta hoon. |
| I couldn't agree more. | Main poori tarah sehmat hoon. |
| That's true. | Yeh sach hai. |
| I think so too. | Mujhe bhi aisa lagta hai. |
| Exactly! | Bilkul! |
| You have a point. | Aapki baat mein dum hai. |

## Disagreeing (Politely)

| English | Hindi |
|---------|-------|
| I don't think so. | Mujhe aisa nahi lagta. |
| I'm not sure about that. | Mujhe isme shak hai. |
| I see it differently. | Mera nazariya alag hai. |
| I beg to differ. | Main alag sochta hoon. |
| That's not how I see it. | Mujhe aisa nahi lagta. |
| I'm afraid I disagree. | Sorry, main agree nahi karta. |
| With respect, I think... | Respect ke saath, mujhe lagta hai... |
| I understand, but... | Main samajhta hoon, lekin... |
