# Phone Call Conversations

> Common phrases for phone calls.

---

## Answering the Phone

| English | Hindi |
|---------|-------|
| Hello? | Hello? |
| Hello, who's speaking? | Hello, kaun bol raha hai? |
| This is Rahul speaking. | Main Rahul bol raha hoon. |
| Speaking. | Haan, main hi hoon. |
| How can I help you? | Main aapki kya madad kar sakta hoon? |

---

## Making a Call

| English | Hindi |
|---------|-------|
| Hi, is this Priya? | Hi, kya yeh Priya hai? |
| Can I speak to Mr. Sharma? | Kya main Mr. Sharma se baat kar sakta hoon? |
| I'm calling about... | Main... ke baare mein call kar raha hoon. |
| Is this a good time to talk? | Kya abhi baat karna theek hai? |
| I got your number from... | Mujhe aapka number... se mila. |

---

## During the Call

| English | Hindi |
|---------|-------|
| Can you hear me? | Kya aapko meri awaaz aa rahi hai? |
| The line is breaking up. | Line kat rahi hai. |
| Could you speak louder? | Kya aap zor se bol sakte ho? |
| Sorry, I didn't catch that. | Sorry, mujhe samajh nahi aaya. |
| Can you repeat that? | Kya aap dobara bol sakte ho? |
| Hold on a moment. | Ek second ruko. |
| Let me check. | Main check karta hoon. |
| I'll call you back. | Main aapko wapas call karta hoon. |

---

## Ending the Call

| English | Hindi |
|---------|-------|
| I have to go now. | Mujhe ab jaana hai. |
| Talk to you later. | Baad mein baat karte hain. |
| Thanks for calling. | Call karne ke liye shukriya. |
| It was nice talking to you. | Aapse baat karke achha laga. |
| Bye, take care! | Bye, apna khayal rakhna! |
| I'll get back to you. | Main aapko wapas batata hoon. |

---

## Missed Calls & Voicemail

| English | Hindi |
|---------|-------|
| Sorry, I missed your call. | Sorry, mujhse aapki call miss ho gayi. |
| I saw your missed call. | Maine aapki missed call dekhi. |
| Please leave a message. | Kripya message chhod dijiye. |
| I'll try calling again later. | Main baad mein dobara call karunga. |
| Can you call me back? | Kya aap mujhe wapas call kar sakte ho? |

---

## Wrong Number

| English | Hindi |
|---------|-------|
| Sorry, wrong number. | Sorry, galat number hai. |
| I think you have the wrong number. | Lagta hai aapka number galat hai. |
| There's no one here by that name. | Yahan is naam ka koi nahi hai. |
| What number did you dial? | Aapne kaun sa number lagaya? |
