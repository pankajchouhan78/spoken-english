# Shopping Conversations

> Common phrases for shopping situations.

---

## Entering a Shop

| English | Hindi |
|---------|-------|
| I'm just looking, thanks. | Bas dekh raha hoon, shukriya. |
| Can you help me find something? | Kya aap mujhe kuch dhundhne mein madad kar sakte ho? |
| Do you have this in a different size? | Kya yeh alag size mein hai? |
| Do you have this in another color? | Kya yeh doosre rang mein hai? |
| Where can I find the shoes section? | Shoes section kahan hai? |

---

## Asking About Products

| English | Hindi |
|---------|-------|
| How much is this? | Yeh kitne ka hai? |
| What's the price of this? | Iska daam kya hai? |
| Is this on sale? | Kya yeh sale mein hai? |
| Do you have any discounts? | Koi discount hai? |
| Is this the final price? | Kya yeh last price hai? |
| Can you give me a better price? | Kya aap thoda kam kar sakte ho? |

---

## Trying Things

| English | Hindi |
|---------|-------|
| Can I try this on? | Kya main yeh try kar sakta hoon? |
| Where is the trial room? | Trial room kahan hai? |
| This doesn't fit me. | Yeh mujhe fit nahi aa raha. |
| Do you have a bigger size? | Kya bada size hai? |
| Do you have a smaller size? | Kya chhota size hai? |
| This fits perfectly! | Yeh bilkul fit hai! |

---

## Making a Decision

| English | Hindi |
|---------|-------|
| I'll take this one. | Main yeh le lunga. |
| I'll think about it. | Main sochta hoon. |
| I'm not sure about this. | Mujhe isme confusion hai. |
| Can I see something else? | Kya aur kuch dikha sakte ho? |
| I don't like this. | Mujhe yeh pasand nahi. |
| This is exactly what I wanted! | Yahi toh chahiye tha mujhe! |

## Payment

| English | Hindi |
|---------|-------|
| Where do I pay? | Payment kahan karna hai? |
| Do you accept cards? | Kya card chalega? |
| Can I pay by UPI? | Kya UPI se pay kar sakta hoon? |
| Do you have change? | Kya aapke paas chhutta hai? |
| Can I get a receipt? | Kya mujhe receipt mil sakti hai? |
| Is there any warranty? | Koi warranty hai? |

## Returns & Exchange

| English | Hindi |
|---------|-------|
| Can I return this? | Kya main yeh wapas kar sakta hoon? |
| I want to exchange this. | Main yeh exchange karna chahta hoon. |
| This is defective. | Yeh kharab hai. |
| I have the receipt. | Mere paas receipt hai. |
| What's your return policy? | Aapki return policy kya hai? |
| Can I get a refund? | Kya mujhe refund mil sakta hai? |
