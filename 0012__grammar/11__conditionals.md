# Conditionals (If Clauses)

> Express conditions and their results.
> "If this happens, then that happens."

---

## Four Types of Conditionals

| Type | Name | Use |
|------|------|-----|
| Zero | General Truth | Always true facts |
| First | Real/Possible | Likely future situations |
| Second | Unreal Present | Imaginary present/future |
| Third | Unreal Past | Imaginary past |

---

## Zero Conditional

> Facts, general truths, things that always happen.

### Structure: If + Present Simple, Present Simple

| If Clause | Main Clause |
|-----------|-------------|
| If you heat water, | it boils. |
| If it rains, | the ground gets wet. |
| If you mix red and blue, | you get purple. |

**Examples:**
- **If** you press this button, the door **opens**.
- Water **freezes** **if** the temperature is below 0°C.
- **If** I eat too much, I **feel** sick.

> Can use "when" instead of "if" (same meaning)

---

## First Conditional

> Real possibility in the future.

### Structure: If + Present Simple, will + V1

| If Clause | Main Clause |
|-----------|-------------|
| If it rains, | I will stay home. |
| If you study hard, | you will pass. |
| If she calls, | I will answer. |

**Examples:**
- **If** you **come** early, we **will go** together.
- I **will help** you **if** you **need** me.
- **If** he **doesn't hurry**, he **will miss** the train.

**Variations:**
- If + Present, can/may/might + V1
- If you finish, you **can** go.
- If it rains, I **might** stay home.

---

## Second Conditional

> Unreal/imaginary present or future. Unlikely situations.

### Structure: If + Past Simple, would + V1

| If Clause | Main Clause |
|-----------|-------------|
| If I had money, | I would buy a car. |
| If she knew the answer, | she would tell us. |
| If I were rich, | I would travel the world. |

**Examples:**
- **If** I **had** wings, I **would fly**.
- **If** I **were** you, I **would accept** the offer.
- She **would be** happy **if** she **got** the job.

> **Note:** Use "were" for all subjects with "if" (formal)
> If I **were** (not "was") a bird...
> If she **were** here...

---

## Third Conditional

> Imaginary past. Things that didn't happen.

### Structure: If + Past Perfect, would have + V3

| If Clause | Main Clause |
|-----------|-------------|
| If I had studied, | I would have passed. |
| If she had called, | I would have answered. |
| If we had left early, | we wouldn't have missed the train. |

**Examples:**
- **If** I **had known**, I **would have helped**.
- She **would have come** **if** you **had invited** her.
- **If** he **hadn't lied**, I **wouldn't have been** angry.

> Expresses regret about the past.

---

## Mixed Conditionals

### Type 3 + Type 2 (Past condition → Present result)

**If** I **had studied** medicine, I **would be** a doctor now.
(I didn't study medicine in the past → I'm not a doctor now)

### Type 2 + Type 3 (Present condition → Past result)

**If** I **were** taller, I **would have played** basketball.
(I'm not tall now → I didn't play basketball)

## Summary Table

| Type | If Clause | Main Clause | Example |
|------|-----------|-------------|---------|
| 0 | Present Simple | Present Simple | If you heat ice, it melts. |
| 1 | Present Simple | will + V1 | If you study, you will pass. |
| 2 | Past Simple | would + V1 | If I had money, I would travel. |
| 3 | Past Perfect | would have + V3 | If I had known, I would have helped. |

## Unless = If...not

| If...not | Unless |
|----------|--------|
| If you **don't** hurry, you'll be late. | **Unless** you hurry, you'll be late. |
| If she **doesn't** call, I won't go. | **Unless** she calls, I won't go. |
| If it **doesn't** rain, we'll play. | **Unless** it rains, we'll play. |

> **Unless** already means "if not" - don't add "not" again!
> Unless you don't come ❌ → Unless you come ✅

---

## Other Conditional Words

| Word | Meaning | Example |
|------|---------|---------|
| provided (that) | if, on condition | I'll go provided you come. |
| as long as | if, only if | You can stay as long as you're quiet. |
| in case | for the possibility | Take an umbrella in case it rains. |
| supposing | what if | Supposing you failed, what then? |
| even if | regardless | I'll go even if it rains. |

## Wish + Conditionals

### Wish + Past Simple (Present wish)
- I **wish** I **had** more money. (I don't have now)
- I **wish** I **were** taller. (I'm not tall)
- I **wish** I **knew** the answer. (I don't know)

### Wish + Past Perfect (Past wish/regret)
- I **wish** I **had studied** harder. (I didn't study)
- I **wish** I **hadn't said** that. (I said it)

### Wish + Would (Future wish/complaint)
- I **wish** you **would stop** talking. (Please stop)
- I **wish** it **would rain**. (I want rain)

---

## Common Mistakes

| Wrong ❌ | Right ✅ |
|---------|---------|
| If I will see him... | If I **see** him... |
| If I would have money... | If I **had** money... |
| If I was you... | If I **were** you... |
| Unless you don't come... | Unless you **come**... |
| If I had knew... | If I had **known**... |
| I would helped if... | I would **have helped** if... |

---

## Conditional Usage Tips

| Situation | Use |
|-----------|-----|
| Scientific fact | Zero: If you drop it, it falls. |
| Weather prediction | First: If it rains, I'll stay home. |
| Giving advice | Second: If I were you, I would go. |
| Expressing regret | Third: If I had known, I would have come. |
